# SuprConGPU API documentation

Welcome to the [API documentation of SuprConGPU](https://suprcongpu.gitlab.io/suprcongpu/).


### Generating documentation locally

This documentation can also be built locally after cloning the SuprConGPU repository. To do so, make sure that doxygen and its dependencies are installed, e.g. on Ubuntu 20.04:
```shell
sudo apt install doxygen-latex doxygen-doc doxygen-gui graphviz
```

Then run the following from the root directory of the repository.
```shell
doxygen docs/doxygen.conf
```
