# Python tools for SuprConGPU
A collection of scripts

## External packages required
Python3 should already be installed on your system, but we also need:
- virtualenv

## Setup the virtual environment
Simply run:
```
./setup_virtualenv.sh
```

## Usage
To activate the virtual environment write:
```
source venv/bin/activate
```
You can then run the scripts, e.g.
```
python plot_fermi_surface.py
```

To deactivate the virtual environment write:
```
deactivate
```
